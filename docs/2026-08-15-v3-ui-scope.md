# SchoolSafe V2 — Prototype V3 UI

Branche de travail : `prototype-v3-ui`

Sauvegarde : `backup-schoolsafe-v2-avant-v3-2026-08-15`

## Objectif
Harmoniser uniquement les couleurs de l’espace interne SchoolSafe V2 sans changer sa structure, ses textes, ses fonctions, ses mouvements ou ses animations.

## Zone protégée
Doivent rester strictement identiques :
- splash d’ouverture ;
- écran galerie/enfants ;
- photos et rotations ;
- écran d’authentification ;
- saisie e-mail/téléphone, mot de passe et code ;
- écran de configuration de l’école ;
- textes, boutons et actions ;
- JavaScript et logique métier ;
- cube 3D et toutes ses animations ;
- backend, API, Supabase, serveur et sécurité.

## Zone autorisée
Uniquement `.workspace-screen` et ses descendants.

Les changements V3 doivent être limités à :
- couleurs de fond ;
- couleurs de texte ;
- couleurs de bordure ;
- palette des états et domaines ;
- gradients de couleur déjà présents ;
- harmonisation chromatique des cartes et de la navigation.

Aucune taille, position, marge, padding, rayon, animation, transition, transform, grille, flex ou typographie ne doit être modifiée dans cette première passe.

## Méthode
Le fichier applicatif actuel n’est pas modifié. La V3 est une surcouche `app/v3-theme.css` injectée uniquement par `app/v3-preview.html`. Ainsi `app/index.html`, `app/styles.css` et `app/app.js` restent identiques à la sauvegarde pendant la phase de validation visuelle.
